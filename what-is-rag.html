What is RAG?

RAG stands for Retrieval Augmented Generation.

RAG combines search systems and AI models to generate better and more accurate answers.

How It Works

  1. User asks a question.
  2. System searches documents.
  3. Relevant information is retrieved.
  4. LLM generates an answer.

Benefits

  • More accurate answers
  • Uses latest data
  • Reduces hallucinations
